# Code of Conduct

**Classification: UNCLASSIFIED // FOR OFFICIAL USE ONLY (FOUO)**

## Our Pledge

In the interest of fostering a secure, professional, and collaborative environment, we as contributors and maintainers pledge to make participation in our project a harassment-free and productive experience for everyone, while maintaining the highest standards of security and compliance required by the Department of Defense.

## Our Standards

### Positive Behavior
- Using professional and respectful language
- Being respectful of differing viewpoints and experiences
- Gracefully accepting constructive criticism
- Focusing on what is best for the organization
- Showing empathy towards other community members
- Maintaining security and compliance standards
- Following proper information handling procedures

### Unacceptable Behavior
- The use of sexualized language or imagery
- Trolling, insulting/derogatory comments, and personal attacks
- Public or private harassment
- Publishing others' private information without permission
- Sharing classified or sensitive information
- Violating security protocols or compliance requirements
- Other conduct which could reasonably be considered inappropriate in a professional setting

## Security Responsibilities

### Information Handling
- Properly mark and handle classified information
- Follow need-to-know principles
- Report security violations promptly
- Maintain proper access controls
- Protect sensitive information

### Compliance
- Adhere to DoD security policies
- Follow OPSEC guidelines
- Maintain required certifications
- Complete required training
- Report compliance violations

## Our Responsibilities

Project maintainers are responsible for:
- Clarifying standards of acceptable behavior
- Taking appropriate corrective action
- Maintaining project security
- Ensuring compliance with regulations
- Protecting sensitive information
- Managing access control
- Monitoring security posture

## Scope

This Code of Conduct applies within:
- Project spaces
- Public spaces when representing the project
- Official communications
- Online interactions
- In-person events

## Enforcement

### Reporting
- Report violations to project maintainers
- Follow security incident procedures
- Document compliance issues
- Maintain confidentiality
- Preserve evidence

### Consequences
1. Warning
2. Temporary ban
3. Permanent ban
4. Security investigation
5. Legal action
