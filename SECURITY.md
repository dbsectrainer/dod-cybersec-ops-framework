# Security Policy

**Classification: UNCLASSIFIED // FOR OFFICIAL USE ONLY (FOUO)**

## Security Classification

This project contains sensitive but unclassified information controlled under the designation FOUO. Handle and protect in accordance with DoD 5200.1-R.

## Reporting a Vulnerability

### Critical Vulnerabilities

For critical security vulnerabilities that could lead to:
- Unauthorized access to DoD systems
- Exposure of sensitive information
- Compromise of security controls
- Violation of security boundaries

**Immediate Actions Required:**
1. Do NOT create a public GitHub issue
2. Contact the Security Team immediately through secure channels
3. Follow your organization's security incident response procedures
4. Document all findings and actions taken

### Standard Vulnerabilities

For non-critical security issues:
1. Create a GitHub Security Advisory
2. Provide detailed description
3. Include impact assessment
4. Suggest remediation if possible

## Security Requirements

### Access Control
- All contributors must have appropriate security clearance
- Follow the principle of least privilege
- Use PIV/CAC for authentication where required
- Implement role-based access control

### Code Security
- All code must pass SAST/DAST scanning
- Comply with DISA STIGs
- Follow secure coding guidelines
- Regular vulnerability assessments

### Data Protection
- Encrypt sensitive data at rest and in transit
- Implement proper key management
- Follow data handling procedures
- Regular backup and recovery testing
